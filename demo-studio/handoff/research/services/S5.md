# S5 — Cobrar con tarjeta (SERVICES): Wompi CO, Stripe US/CA, propinas; México hoy

Commit read: `17d519ac`. Paths under `app/src/main/java/com/example/`.
Base: restaurant `S5.md` (d1b7698) and retail `S5.md`. The card flow (`WompiPaymentOverlay`, `StripePaymentSheet`, `CardCheckoutDecision`, `StripeCardGate`) never asks the business type. Services differ only in the tip default and in the where-gate; several restaurant problems are fixed since.

## 1. What it does, who, which device
- **Colombia — Wompi:** the cashier types the card (number, "MM / AA", CVC, name) on the phone; card-not-present. No tip screen.
- **US / Canada — Stripe Tap to Pay:** the client taps the card on the phone. **Services ask for a tip by default** (`ServicesRules.kt:34` `tipDefaultOn = true`, read through `OwnerSettings.resolveAskForTip`), like restaurants and unlike shops/pharmacies. The tip screen comes first: "Add a tip?" / "¿Agregar propina?" with 15 % / 18 % / 20 % (`StripeTip.PERCENTS`), "No tip", "Other amount"; a tap on a preset or "No tip" starts the charge.
- **Mexico — no card today.** `sync/CardCountryGate.kt` maps only US/CA → STRIPE and CO → WOMPI; MX → NONE (searched `"MX"` in `sync/`: only RFC label, payment-method example "Mercado Pago" and the IVA 16 % preset). So a Mexican salon has no Card row in Payment methods and no Card button; the set-up link says "Configurar QR". Stripe MX is not in this commit.
- PE CL EC AR PA BR: no card.
- Devices: owner phone sets it up; owner phone, staff phone and counter tablet can charge (same pay body). In US/CA the device itself must be able to tap (Android 13 + NFC); `TapToPayMode.REAL_TAP_TO_PAY = false` (`sync/TapToPayMode.kt:25`): the build still uses Stripe's simulated reader.
- **The tip belongs to the business.** There is no "who did the service" on a sale (searched `performedBy|assignedEmployee|staffId|stylist|professional` in `data/`: nothing); the sale stores only `employeeName` = whoever was signed in at the till (`CheckoutActions.kt:395`). So a salon cannot see which stylist earned a tip.
- Trades: no difference between the 41 trades.
