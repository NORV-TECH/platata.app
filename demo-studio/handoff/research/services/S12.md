## 1. What differs for services
- No "Ventas fiado (a crédito)" row (services have no tab; `ShareAccountantScreen.kt:183`).
- The REPORTS-11 lines after "Ventas netas" (`EmployeePayActions.kt:358-367`) carry the services extras:
  - "Cargos por servicio / Taxas de serviço / Service charges" = the "A domicilio" / "Recogen y entregan" trip charges (where-mode fee).
    A salon is born WITHOUT the restaurant's optional service charge (Mercadeo 3.3 R5: `seedServiceFee` only for restaurants; commit
    `3307904b` proves "un salón nace sin el cargo"), so in a services shop this row is only trip money.
  - "Propinas / Gorjetas / Tips" in US/CA (services ask for a tip by default).
- "Pagado a proveedores" + "Facturas de proveedores": services do have the invoice row (`ServicesRules.hasSupplierInvoiceRow = true`) —
  dye, polish, oil, vaccines bought from distributors.
- "Pagado a empleados": same monthly rule (only months entirely inside the range; no row at all on a shorter range, BACKOFFICE-1). There is
  no commission figure (S15).
- Changed since the restaurant file (BACKOFFICE-1 / BACKOFFICE-2 B): one name "Resumen para el contador", first row "Ventas netas" (same
  number as Reports), every row has a Copy icon besides long-press, plurals fixed, the PDF wraps and goes to more pages, the intro is
  gender-neutral ("tu contador o contadora"), Colombia hides the always-unknown Wompi fee row and shows instead "Aún no conocemos las
  comisiones de tarjeta. Las ventas con tarjeta se muestran antes de comisiones." under the card row; failed shares now say so.
  Restaurant A1, A2, A3, A4, A5, A7, A8, A10 are closed.
