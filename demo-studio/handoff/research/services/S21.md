## 1. What works offline for a salon / vet / workshop

| Action | Owner phone | Counter tablet / employee phone |
|---|---|---|
| Charge a service or product (cash, QR picture, other method) | Works, local | Works, saved locally, "Pendiente de enviar" strip |
| **Book an appointment** ("Agendar" → "¿Cuándo?" → Guardar) | Works: saved as an open ticket in the phone's DB | Works locally; reaches the owner's Agenda only when that device is back online |
| Reschedule / no-show / cancel / charge a booking (Agenda) | Works, local | Works on bookings that device already holds |
| "Sobrecupo" warning / busy slots in the time picker | Only knows bookings already on THIS device (`BookingScreen.kt:110-122` reads local open orders) | Same |
| Setup walk (41 trades, services, options, prices) | Works: the researched catalogue is inside the app (`assets/catalogo_investigado`); no dictionary download (`needsProductDictionary = false`) | — |
| Stock moves on a product sale | On the device that sold | Same |
| Card | CO (Wompi) / US-CA (Stripe): grey "Tarjeta · Sin conexión", tap explains | Same |
| US/CA tip | The tip screen is part of the Stripe card charge, so offline there is NO tip prompt (cash sale has no tip) | Same |

## 6. UX/UI problems
1. Double-booking risk across devices offline: each device's slot picker and "sobrecupo" only see bookings it already holds (`BookingScreen.kt:110-122`), so the tablet and the owner can book the same chair at the same hour while one is offline, with no warning. Fix: on a non-owner device with held items, show "Puede haber citas de otros equipos que aún no llegan" in "¿Cuándo?". Small (possible, timing).
2. The held strip counts bookings as "ventas" (`getUnsyncedOrderCount` counts every unsynced order, `data/PosDao.kt:478-483`): an offline tablet that only booked 2 appointments says "2 ventas guardadas". Fix: for services say "2 ventas o citas guardadas". Small.
3. Same as restaurant 3 (owner cannot see an offline register holding sales/bookings) — still open. Small for a one-person salon.
4. Not new: where-modes not syncing (V8 problem 1) also means offline/online makes no difference on staff devices there.
