Commit read: `6736ddfb` (/home/claude/app-head). Paths under `app/src/main/java/com/example/`.
Same as restaurant S1 (welcome → country → type → name → Google → "Configurando…" → ready → landing), except what follows.

## 1. What differs
- Owner's phone only, same as restaurant. Shop and pharmacy are ONE tile ("Tienda") with a two-way switch inside the pitch card: "Tienda" | "Droguería" (Colombia) / "Farmacia" (every other country) (`ui/screens/onboarding/BusinessTypePickerScreen.kt:333-341`, `BusinessTypeOptions.kt:375-381`). Pharmacy = RetailRules with zero overrides (`data/business/PharmacyRules.kt`), so after this switch nothing behaves differently; only the name word changes ("Droguería · Colombia · COP" on the ready card).
- **A barcode-list download sits between Google and the creation.** A shop/pharmacy cannot be created without it (`OnboardingNavGraph.kt:68-73`, `DraftCreateResult.NEEDS_DICTIONARY`). "Ahora no" sends the person back to the country step with the draft kept and NOTHING created (`OnboardingNavGraph.kt:433-452`). Needs internet; ~30 MB (`ui/pos/DictionaryDownload.kt:191` `DICT_APPROX_SIZE_MB = 30`; file `lookup_dictionary.db` from GitHub releases, `res/values/strings.xml:3386`). Skipped if this phone already has it (second business).
- Lands on the **Scan register** (no Teclado/Catálogo tab row), not on an empty menu (`OnboardingNavGraph.kt:472`, `HomeScreen.kt:366,609`).

## 2. Setup / what creation seeds (shop-specific)
- 24 ready-made categories (`data/repo/SeedStore.kt:139-163`): Bebidas, Snacks, Lácteos, Carnes, Panadería, Cereales, Frutas y Verduras, … **Licores, Tabaco**, Farmacia, Mascotas, Juguetes, Otros. Same list for a pharmacy. They cannot be deleted (`RetailRules.mayDeleteCategory = false`) nor renamed (isSystem). All show as chips on the counter tablet / waiter phone Catálogo (`ProductLibraryView.kt:206` lists every category, empty or not).
- Fiado tender seeded inactive but it has no switch and needs none (Fiar button, see S6).
- An optional paused service charge "Cargo por servicio" 10 % (CO) / 15 % (others) is seeded for shops too (`SeedStore.kt:204-227`, called at creation `ui/pos/WorkspaceActions.kt:502`).
- No products. The 3,523-item "Sin código" catalogue (fruit, meat, bread…) ships inside the app for es/pt/en/fr.

## 6. UX problems
1. **"3.523 productos con código, listos" is wrong.** 3,523 is the row count of the NO-barcode catalogue (`assets/no_barcode_catalog/catalog_es.db`, table `items`: name, category, icon, unit — no barcode column; counted). The barcode list is the separate ~30 MB download; its row count is not in the repo. Fix: "3.523 productos sin código listos + lista de códigos de barras" or count the real dictionary.
2. **Dictionary page title "Creando tu negocio…" while it is only asking permission to download**, and "Ahora no" silently throws him back to the country step with nothing created (`DictionaryDownloadScreen.kt:124`, `OnboardingNavGraph.kt:441`). Fix: title "Falta la lista de códigos de barras" and say "Sin ella no podemos crear tu tienda".
3. Shops are seeded "Licores" and "Tabaco" categories that show as chips on the tablet/waiter Catálogo and can be neither deleted nor renamed (`SeedStore.kt:151,154`; `RetailRules.kt` mayDeleteCategory=false). Bad on a demo (brief: no alcohol/cigarettes) and odd for a pharmacy.
4. A shop is seeded a restaurant "Cargo por servicio" (`SeedStore.kt:204`). Small; fix: seed only for restaurants.
5. Name placeholder "ej. Mi café, salón" on a shop flow (`biz_setup_field_placeholder`). Small.
6. US/CA English pitch says "Fiado: …" but every other English screen says "Tab" (`biz_pitch_shop_fiado` vs `fiado_row_name` "Tab"). Small.
7. Restaurant S1 #7 (Panama "USD") is fixed at this commit (CLAUDE.md FIX-3 item 6).
