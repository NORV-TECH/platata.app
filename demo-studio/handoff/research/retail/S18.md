# S18 — Combos (SHOP / PHARMACY)

Commit read: `6736ddfb`. Paths under `app/src/main/java/com/example/`.

## 1. A shop has NO combos
- `RetailRules.combosEngineRuns = false`, `combosManagementUiShown = false`, `discountsScreenHasComboTab = false` (`data/business/RetailRules.kt:39-40, 78`; pharmacy inherits).
- The only combo door is "Combos" on the restaurant's "Tu menú" (`ui/screens/items/YourMenuScreen.kt:79`); a shop's Items screen has none, the Discounts page has no Combos tab, and the cart never looks for a combo (`ui/pos/CatalogActions.kt:551` returns at once). No "Combo" pill on shop tiles.
- So none of restaurant S18's screens or problems apply to a shop.

## 2. What a shop can do instead
Only a per-item % or fixed-amount discount (S16), e.g. "Liquidación / producto dañado" on one product. There is **no quantity promo** ("2x1", "Lleva 3, paga 2", "segunda unidad a mitad de precio"): `DiscountConfig` has no minimum-quantity field (`data/DiscountConfig.kt:18-48`). "not found in code".

## 3. Demo path
None — do not show combos in a shop demo. Use S16 (a clearance discount on one product).

## 4. UX problems
1. Possible product gap: quantity promos ("2x1", "lleva 3 paga 2") are the most common shop and pharmacy promotion and do not exist. Not a bug; for Monti to decide.
