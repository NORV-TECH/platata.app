# S19 — Otro celular o tablet: Conexiones (SHOP / PHARMACY)

Commit read: `6736ddfb`. Paths under `app/src/main/java/com/example/`.
The Connections page, the gate, the 9-register cap, "Conectar" for an employee phone, pairing codes, the nudge and US/CA free are the **same as restaurant S19** (restaurant problems 2, 3, 5 fixed by BACKOFFICE-1 item 14). What the shop's extra devices look like differs:

## 1. Differences
### 1.1 Counter tablet in a shop — `ui/screens/mamapos/MamaPosScreen.kt:811-817`
- Tabs **"Escanear" · "Catálogo" · "Ventas"** (pt "Escanear · Catálogo · Vendas"; en "Scan · Library · Sales"); "Teclado" is a link inside Catálogo. No "Abiertas" tab, no tables, no kitchen.
- Scan pane (`ui/screens/mamapos/MamaScanPane.kt`, `ui/pos/TabletScanActions.kt`): camera box or a USB/Bluetooth reader (`ReaderKeyBuffer`). It adds **known products only**: unknown code = red "No está en tu catálogo" | "Não está no seu catálogo" | "Not in your catalog"; no price = "Este artículo no tiene precio". It never creates a product (its catalog is a mirror of the owner's).
### 1.2 Employee phone in a shop — `ui/screens/onboarding/MiniPosScanTab.kt:80-150`
Scan card with rows "Inventario" (only with "Controlar el stock"), "Reportes" (only with "Ver reportes"), "Clientes", "Sin código", "Teclado"; a "download the dictionary" banner first while the ~30 MB barcode file is missing on that phone. Unknown barcodes CAN be created here (shared scanned catalog `synced_products`).
### 1.3 Kitchen screen → "Pantalla de trastienda" | "Tela dos fundos" | "Back-room screen" (`RetailRules.kt:82`) — same KDS engine; rarely useful in a tienda.
### 1.4 Stock and the extra devices
A sale moves stock ONLY on the device that rang it (`data/repo/StockStore.kt:47-86`; mirrored orders never move the shelf, `:89-100`). The tablet's shelf is then reset by the owner's next reference push (it carries the owner's variations, `data/repo/BranchSnapshotStore.kt:99`). **Result: sales made on the tablet or an employee phone never lower the owner's stock.**

## 2. Demo path (CO, owner phone + tablet, ~10 taps)
Owner: flag → Ajustes → "Conexiones" → "Conectar" → "Tablet de mostrador" → name "Caja 2" → code shown. Tablet: "Ya uso Platata" → "Tablet de mostrador" → type the code → pick Ana → PIN → tab "Escanear" → scan a soda → "Cobrar $ 2.500" → "Efectivo".

## 3. UX problems
1. **Tablet / staff-phone sales never take stock off the owner's count** (`StockStore.kt:47-100`, `BranchSnapshotStore.kt:99`): the owner sells 10 sodas from the tablet, Inventario still says 24. BLOCKS A DEMO that shows a tablet AND inventory. Fix: the owner applies stock moves for mirrored PAID orders once (keyed by order id), and the tablet stops moving its own mirror.
2. A tablet cashier cannot add an unknown product while a customer waits — only the message "No está en tu catálogo" and no way forward (no "Sin código" price box from the scan pane message). Small. Fix: offer "Cobrar con precio a mano" (the Keypad) in the message.
3. Each employee phone must download the ~30 MB dictionary (banner) — slow on shop data plans. Small; say it in the demo.
